Setup guide

How to set up WFU templates in Google Drive

All 41 templates are provided as .xlsx and .docx files. When uploaded to Google Drive, they automatically convert to native Google Sheets and Google Docs.

Step 1: Create the folder

1.
Go to drive.google.com and sign in with your WFU Google account.
2.
Click New > Folder and name it WFU CM and PM Templates.
3.
Open the folder. Copy the folder ID from the URL bar. It is the long string after /folders/. Example: drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz

Step 2: Upload the template files

4.
Inside the folder, click New > File upload and select all 41 template files.
5.
After uploading, right-click each file and choose Open with > Google Sheets (for .xlsx) or Open with > Google Docs (for .docx). This creates a native Google version.

Bulk convert tip: To auto-convert all files on upload, go to Google Drive Settings (gear icon) > check "Convert uploads to Google Docs editor format". Then re-upload.

Step 3: Share the folder

6.
Right-click the folder > Share. Set access to "Anyone at Wake Forest University with the link" and permission to Viewer.
7.
For templates people need to fill in, have them click File > Make a copy so they get their own editable version. The original stays clean.

Step 4: Connect to the HTML tool

8.
Open the HTML tool file (WFU_CM_PM_101_Simple.html) in a text editor.
9.
Find and replace YOUR_FOLDER_ID with your actual folder ID from Step 3. There are 75 occurrences.
10.
Save the file and upload to your GitHub repository. All template links in the tool will now open your Google Drive folder.

Even better: For each template, you can get the direct Google Docs/Sheets link (click Share > Copy link) and replace the folder link with the direct link. This opens the specific template instead of the folder.
